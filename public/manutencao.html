🧹 Faxina de Fichas Locais

Fichas locais (estadias, vouchers…) cujo ID não bate com nenhum cliente atual do Notion. Elas se dividem em dois casos, tratados diferente pra nunca apagar dado de cliente real.

🔗 Desalinhadas 0

Mesmo cliente, ID trocado — existe um cliente vivo no Notion com o mesmo nome. Não se apaga: re-vincule pra juntar as estadias na ficha do ID certo (a origem some, de forma reversível).

…

🗑️ Órfãs de verdade 0

Nem o ID nem o nome batem com cliente vivo. Pode ser sobra de cliente apagado (seguro limpar) ou um cliente que mudou de nome/foi readicionado — nesse caso escolha o cliente vivo à direita e Re-vincule em vez de apagar. Remoção padrão é reversível.

…

Nada aqui toca no Notion. As remoções e re-vínculos mexem só nas fichas locais (Supabase) e, por padrão, são reversíveis.
