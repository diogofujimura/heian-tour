# Protocolo do projeto Heian Tour

1. No **início da sessão**, leia `ESTADO-DO-PROJETO.md` UMA vez. Ele é a fonte única de verdade (estágio atual, pendências, regras).
2. **Não releia** esse arquivo a cada comando — o conteúdo já está no contexto da sessão. Só releia se o usuário disser que algo mudou.
3. Confira o carimbo "Última atualização" no topo pra saber se está em dia.
4. Ao **terminar a sessão** (ou uma leva de mudanças), acrescente **uma linha** no Log do `ESTADO-DO-PROJETO.md` (data · seu nome · o que mudou) e atualize o carimbo. Não reescreva o arquivo inteiro.
5. Siga as "Regras invioláveis" desse arquivo à risca (não quebrar Notion/Sheets/Hostinger/GitHub).
